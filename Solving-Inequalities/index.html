Solving Linear Inequalities

Compare solving a linear equation with solving a linear inequality:

Linear Equation

Solve:   3x − 4 = 2

3x = 2 + 4

3x = 6

x = 2   (1 single solution)

Linear Inequality

Solve:   3x − 4 ≤ 2

3x ≤ 6   →   x ≤ 2

*Check with x = 0:   3(0) − 4 = −4 ≤ 2 (True!)

Golden Rules of Inequalities

When Does the Inequality Sign Reverse?

Rule 1

Interchanging the sides reverses the inequality sign.

If 5 > x, then reading from x:

x < 5

Rule 2

Multiplying or dividing both sides by a negative number reverses the inequality sign.

Start with true statement: 2 < 6

Divide both sides by −2:

−1 > −3  (sign flips!)

Part A • Special Cases

4. Solve for x and comment on your solutions:

a)   3x + 1 > 3(x + 2)

b)   5x + 2 < 5(x + 1)

c)   2x − 4 ≥ 2(x − 2)

d) Comment on your solutions to a, b and c.

a) 3x + 1 > 3x + 6 ⇒ 1 > 6 (False) → No solutions

b) 5x + 2 < 5x + 5 ⇒ 2 < 5 (Always true) → True for all real x

c) 2x − 4 ≥ 2x − 4 ⇒ −4 ≥ −4 (Always true) → True for all real x

d) Comment: When the x terms cancel out, the inequality is either never true (no solution) or always true (infinitely many solutions, x ∈ ℝ).

Plenary • Spot the Error

Mark My Work

A student tried to solve and graph 8 − 3x < 29. Find the mistakes in their working and number line:

Student's Work (Contains Errors!)

8 − 3x < 29

(−8 from both sides)

−3x < 21

(÷ 3)

−x < 7

x < −7

Correct Solution
  • Mistake 1: Dividing/multiplying by −1 (or −3) requires reversing the inequality sign from < to >.
  • Mistake 2: Because x > −7, the arrow on the number line must point to the right, not the left.
−3x < 21   ⇒   x > −7
