Power Equations

Solving equations involving integer powers, roots, rational proportions, and calculator approximations

Example 1 • Even Power

Solving Basic Power Equations

Solve for x

x2 = 25

Solution

x = ±√25 = ±5

Both 52 = 25 and (−5)2 = 25 are valid solutions.

Key Distinction

Equation vs. Principal Square Root

If x2 = k where k > 0, then x = ±√k.

Solving an Equation

x2 = 25

x = ±5

Two solutions (positive and negative)

VS
Principal Square Root

√25

= 5

Refers only to the positive root

Example 2 • Odd Power

Solving Cubic Power Equations

Solve

x3 = 8

*Does this require ± ?

Solution

x = 3√8 = 2

No ± required! Because (−2)3 = −8 ≠ 8, there is only one real solution.

Example 3 • Higher Even Power

Fourth Power Equations

Solve

x4 = 10,000

*Does this require ± ?

Solution

x = ±4√10,000 = ±10

Yes, ± is required! Since the exponent 4 is even, both 104 = 10,000 and (−10)4 = 10,000.

Core Algebraic Rules

General Rules for xn = k

Odd Exponent (n = 3, 5, 7...)

If n is odd and xn = k, then:

x = n√k

Works for positive, zero, and negative values of k. Single unique solution.

Even Exponent (n = 2, 4, 6...)

If n is even and xn = k where k > 0, then:

x = ±n√k

Always produces two opposite solutions when k > 0.

Example 4 • Algebraic Fractions

Equations Leading to Powers

Solve for x

x2 = 5x

Step-by-Step Solution

x × x2 × x = 5 × 2x × 2 {LCD = 2x, common denominator}
x2 = 10 {equating numerators / cross-multiplying}
x = ±√10

Example 5 • Negative Values

Even vs. Odd Powers with Negatives

Part A (Even Power)

x2 = −25

Part B (Odd Power)

x3 = −8

x2 = −25 → No real solutions exist

Squaring any real number always gives a result ≥ 0.

x3 = −8 → x = −2

Because (−2) × (−2) × (−2) = −8.
