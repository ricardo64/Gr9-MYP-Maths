Comparing Mathematical Statements

x = 5

x < 5

x ≥ 5

1. What do these statements mean?

x = 5: x is strictly equal to 5.

x < 5: x is strictly less than 5 (not including 5).

x ≥ 5: x is greater than or equal to 5 (includes 5).

2. What do they have in common?

All three compare the variable x against the boundary value 5 on a number line.

3. Which one is the odd one out?

x = 5 is an equation (1 single value), whereas x < 5 and x ≥ 5 are inequalities (infinitely many values).

(Or x < 5 because it does not include 5!)
